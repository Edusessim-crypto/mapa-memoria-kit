Vault: `__VAULT__` · Inbox: `80 - INBOX/Inbox.md` · Política: `00 - CENTRAL/REGRAS-DE-MEMORIA.md`

Para cada item não processado:
1. Classifique (permanente / projeto / histórico / descartável) e identifique projeto/área via `00 - CENTRAL/INDEX.md`.
2. Procure se já existe; consolide atualizando a nota existente (siga o fluxo da skill salvar-memoria).
3. Adicione link só quando for relação útil.
4. Marque o item na Inbox como `- [x] … → [[nota destino]] (processado AAAA-MM-DD)`. Só remova o texto depois de confirmado que foi consolidado; na dúvida, deixe e marque "a validar".
5. Descartáveis: marque "descartado — motivo", não apague em silêncio.
Relatório final: tabela item → destino → ação.
