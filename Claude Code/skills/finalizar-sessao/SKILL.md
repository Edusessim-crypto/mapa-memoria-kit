---
name: finalizar-sessao
description: Ao fim de uma sessão de trabalho, registra no Segundo Cérebro só o que tem valor futuro — decisões, padrões, mudanças relevantes, aprendizados, pendências e próximo passo.
---

Vault: `__VAULT__`

1. Revise o que foi feito na sessão (conversa + arquivos alterados/commits).
2. Extraia apenas: decisões aprovadas, padrões travados, mudanças relevantes de estado, aprendizados/erros, pendências novas ou resolvidas, próximo passo. Ignore tentativas descartadas, conversa trivial e raciocínio interno.
3. Localize a nota do projeto via INDEX. Atualize: Status atual, Última atualização, Pendências (marque [x] o que foi resolvido), Próximos passos, linha no Histórico.
4. Decisões → fluxo da skill salvar-memoria (70 - DECISÕES, Padrões Travados se 🔒).
5. Aprendizados reutilizáveis → `40 - CONHECIMENTO/Aprendizados.md` ou `Erros a evitar.md`. Pendências críticas → `00 - CENTRAL/Pendências.md`.
5b. Stack usada/alterada → linha do projeto em `45 - STACK E PADRÕES/Stack Técnica.md`. Padrões técnicos que funcionaram (✅) ou foram rejeitados (❌), sempre com o porquê → `45 - STACK E PADRÕES/Padrões de Código.md`. Preferência nova/alterada → `00 - CENTRAL/Preferências de Trabalho.md` (atualize; marque a antiga como substituída com data).
6. Se o Vault tiver git, faça commit local: "Sessão <data>: <projeto>" (nunca push).
7. Mostre um resumo curto do que foi registrado e onde. Nunca salve segredos nem a conversa inteira.
