# SOP — Publicar site estático

**Quando usar:** sempre que um site em HTML puro precisar ir para o ar.
**Pré-requisitos:** conta na hospedagem e domínio apontado.

## Preparar
1. Conferir se todos os links internos funcionam.
2. Comprimir as imagens grandes.
3. Revisar o título e a descrição de cada página.
4. Remover arquivos de teste e rascunhos.

## Publicar
5. Fazer o commit final no repositório.
6. Publicar na hospedagem escolhida.
7. Conferir o site no celular e no computador.

## Depois
8. Apontar o domínio, se ainda não estiver.
9. Avisar o cliente com o link final.

**Checklist final:**
- [ ] Links conferidos
- [ ] Site aberto no celular
