# Segundo Cérebro — manual de navegação para Claude Code

Este Vault (Obsidian) é a **memória permanente** do dono deste computador. Caminho: a pasta em que este arquivo está.

## Recuperação progressiva (NUNCA leia o Vault inteiro)
1. `00 - CENTRAL/INDEX.md` → identifique projeto/área/cliente.
2. Abra só a nota-âncora indicada (projeto em `10 - PROJETOS/`, marca em `20 - CLIENTES E MARCAS/`).
3. Siga apenas os links necessários (decisões, identidade, prompts).
4. Só então pesquise texto: `rg -l "termo" "<vault>"` (limite a pastas prováveis).
5. Antes de criar/alterar algo de um cliente: `00 - CENTRAL/Padrões Travados.md` (🔒 = não mudar sem pedido explícito).

## Regras
- Não contradiga decisões existentes em silêncio; se conflitar, pergunte.
- Pesquise antes de criar; **atualize > crie**; uma fonte da verdade por assunto.
- Registre só o que tem valor futuro — política em `00 - CENTRAL/REGRAS-DE-MEMORIA.md`.
- Gatilhos de salvar: "guarde isso", "lembre disso", "aprovado", "trave isso", "esse é o padrão", "a partir de agora", "use sempre assim", "adicione ao Segundo Cérebro".
- Gatilhos de NÃO salvar como padrão: "foi só um teste", "não gostei", "descarta", "não use", "esquece essa versão".
- Diferencie FATO / CONCLUSÃO / INCERTO. Versões antigas: `status: substituida`, nunca apagar.
- Nunca grave segredos (o Vault pode ser versionado em git, copiado ou sincronizado). Não use `: | ? * " < > \ /` em nomes de nota. Não altere `.obsidian/`.
