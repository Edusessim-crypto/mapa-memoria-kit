# 🔒 Padrões Travados

> [!danger] Não alterar sem pedido explícito do usuário
> Cada item tem evidência de aprovação definitiva ("aprovado", "trava", "não muda", "esse é o padrão", "use daqui para frente", "obrigatório"…). Antes de criar qualquer peça, texto, site ou código de um cliente, **leia a seção dele**. Detalhes na decisão linkada.

## Geral (todos os projetos)
- 🔒 **Edição ≠ recriação**: alterar só o solicitado, preservar o aprovado.
- 🔒 **Não inventar** dados, métricas, depoimentos, clientes ou telas.
- 🔒 **Versão aprovada vale mais que versão mais nova** (versão rejeitada nunca é referência) → [[Protocolo do Segundo Cérebro]]
