# 📥 Inbox

Entrada rápida: jogue aqui ideias, prints, anotações e decisões soltas. Depois classifique com a pergunta **"Onde isso se encaixa?"** ([[Protocolo do Segundo Cérebro]]) ou rode `/processar-inbox`.

| Se for… | Vai para |
|---|---|
| decisão / aprovação ("trava", "perfeito", "use daqui pra frente") | `70 - DECISÕES` + nota do projeto |
| prompt que funcionou | `50 - RECURSOS/Prompts` ([[Modelo de Prompt]]) |
| aprendizado / erro | [[Aprendizados]] / [[Erros a evitar]] |
| tarefa | seção *Pendências* do projeto + [[Pendências]] |
| cliente novo | `20 - CLIENTES E MARCAS` ([[Modelo de Cliente]]) |
| projeto novo | `10 - PROJETOS` ([[Modelo de Projeto]]) |
